# Требования к качеству (HealthMonitor)

## Функциональные требования
- Сбор метрик доступности, задержек и ошибок от подключённых сервисов.
- Отображение статуса сервисов в дашборде в реальном времени.
- Формирование отчётов за выбранный период.

## Нефункциональные требования
- **Доступность:** 99.9% в месяц.
- **Производительность:** обработка метрик с задержкой < 5 секунд.
- **Масштабируемость:** поддержка роста числа сервисов без деградации.
- **Безопасность:** аутентификация, разграничение прав, шифрование передачи данных.

## Критерии приёмки
- Все критические метрики собираются без потерь.
- Алерты срабатывают при нарушении порогов.
