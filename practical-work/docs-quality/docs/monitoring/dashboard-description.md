# Описание дашборда мониторинга

## Основные панели
- Общее состояние сервисов (OK/Warning/Critical).
- Графики latency (p50/p95/p99), error rate, throughput.
- Список активных алертов и их история.

## Пользователи
- SRE/DevOps — реагирование на инциденты.
- Разработчики — анализ деградаций.
- Менеджмент — сводные показатели доступности.
