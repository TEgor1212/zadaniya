# Стратегия тестирования

## Уровни тестирования
- **Unit:** проверка модулей сбора и агрегации метрик.
- **Integration:** взаимодействие агентов, API и хранилища.
- **E2E:** сценарии пользователя в дашборде.
- **Нагрузочное:** устойчивость при пиковом потоке метрик.

## Инструменты
- Автотесты в CI, статический анализ, тестовые стенды.

## Критерии завершения
- Покрытие критических путей, отсутствие блокирующих дефектов.
